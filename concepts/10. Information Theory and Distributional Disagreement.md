# Information Theory & Distributional Disagreement

These are comprehensive study notes. Every factual claim is cited. References include foundational texts in information theory and applications to machine learning.

Information theory, originally formulated by Claude Shannon in 1948 [3], provides the mathematical framework for quantifying uncertainty, measuring the information content of random variables, and defining the "distance" between probability distributions. 

In the context of modern machine learning and reliability estimation, information-theoretic measures are indispensable tools. They allow us to move beyond binary notions of correctness and formally quantify the disagreement between a model's predicted probability distribution and empirical distributions (or the predictions of other models in an ensemble).

### Conceptual Hierarchy

To understand how these mathematical tools support distributional-disagreement analysis, they can be viewed hierarchically:

```text
Self-Information
        ↓
     Entropy
        ↓
  Cross-Entropy
        ↓
 Proper Scoring Rules
        ↓
  KL Divergence
        ↓
  JS Divergence
```

## 1. Shannon Entropy

Shannon Entropy, denoted as $H(X)$, measures the expected amount of information (or uncertainty) inherent in the possible outcomes of a discrete random variable $X$ [2][3].

The core intuition begins with "surprise" or **self-information**. If an event $x_i$ has probability $P(x_i)$, the surprise of observing $x_i$ is $-\log P(x_i)$. Highly probable events carry little surprise; highly improbable events carry massive surprise. Entropy is simply the expected value of this surprise across all possible outcomes.

For a discrete random variable $X$ with possible outcomes $\{x_1, x_2, \dots, x_n\}$, the entropy is defined as:

$$H(X) = \mathbb{E}_{X \sim P}[-\log P(X)] = - \sum_{i=1}^{n} P(x_i) \log P(x_i)$$

**Properties:**
- **Non-negativity:** $H(X) \ge 0$, with equality if and only if one outcome has a probability of 1 (a deterministic delta function).
- **Maximization:** Entropy is maximized when all outcomes are equally likely (a uniform distribution). Using the method of Lagrange multipliers, one can prove that for $n$ states, the maximum entropy is $\log(n)$, achieved when $P(x_i) = \frac{1}{n}$.
- **Units:** The base of the logarithm determines the unit of entropy: base 2 yields "bits" (or shannons), while base $e$ yields "nats".

**Relevance to AI:**
In machine learning classifiers, **the entropy of the predictive distribution is commonly used as a practical uncertainty proxy**. A flat distribution (e.g., $[0.33, 0.33, 0.34]$) yields high entropy, indicating maximum confusion. A sharp distribution (e.g., $[0.98, 0.01, 0.01]$) yields low entropy, indicating high confidence.

## 2. Cross Entropy and Maximum Likelihood

Cross-Entropy measures the average number of bits needed to identify an event drawn from the true probability distribution $P$, if the coding scheme used is optimized for an estimated (or predicted) distribution $Q$ [2].

$$H(P, Q) = - \sum_{i} P(x_i) \log Q(x_i)$$

Mathematically, cross-entropy can be decomposed into the entropy of the true distribution plus the KL divergence between the true and estimated distributions:
$$H(P, Q) = H(P) + D_{KL}(P \parallel Q)$$

**Equivalence to Maximum Likelihood Estimation (MLE):**
In classification, cross-entropy is mathematically equivalent to negative log-likelihood. Suppose we have a dataset of $N$ samples, where $y^{(i)}$ is the true one-hot label (empirical distribution $P$) and $\hat{y}^{(i)}$ is the model's predicted softmax distribution (estimated distribution $Q$).
Maximizing the log-likelihood is equivalent to minimizing the negative log-likelihood:
$$-\mathcal{L} = - \sum_{i=1}^N \log Q(\hat{y}^{(i)} = y^{(i)})$$
Because $P$ is a one-hot vector (entropy $H(P) = 0$), minimizing $H(P, Q)$ is exactly equivalent to minimizing $D_{KL}(P \parallel Q)$ and equivalent to MLE.

## 3. Proper Scoring Rules

In reliability estimation, we require that the objective function incentivizes the model to output its *true* predictive probabilities. A scoring rule $S(Q, y)$ evaluates the quality of a predicted probability distribution $Q$ against the true event $y$. 

A scoring rule is strictly **proper** if the expected score is optimized *if and only if* the predicted distribution $Q$ exactly matches the true underlying distribution $P$. Proper scoring rules mathematically incentivize truthful probabilities.

### 3.1 Log Loss (Cross-Entropy)
Log loss (Cross-Entropy) is a strictly proper scoring rule.
$$S_{log}(Q, y) = -\log Q(y)$$
However, its penalty is extremely asymmetric. If a model correctly predicts a class but with probability $Q(y) = 0.0001$, the logarithmic penalty is massive. This asymmetric pressure forces deep neural networks to push their predictions toward absolute $1.0$ (overconfidence) during training just to minimize the loss curve, destroying calibration.

### 3.2 Brier Score
The Brier Score is the Mean Squared Error for probabilities, and it is also a strictly proper scoring rule.
$$S_{Brier}(Q, y) = \sum_{c=1}^C (Q(c) - \mathbb{1}_{y=c})^2$$
Unlike log loss, the Brier score's penalty is symmetrically bounded (between 0 and 2). It provides a much gentler penalty that does not brutally punish slight under-confidence. Because it evaluates both the calibration and refinement of a model's probabilities without the asymptotic explosions of log loss, the Brier Score is heavily preferred over Cross-Entropy for evaluating the reliability of a classifier.

## 4. Kullback-Leibler (KL) Divergence

The Kullback-Leibler divergence, also known as relative entropy, measures how one probability distribution $P$ diverges from a second, reference probability distribution $Q$ [1][2].

$$D_{KL}(P \parallel Q) = \mathbb{E}_{X \sim P}\left[ \log \frac{P(X)}{Q(X)} \right] = \sum_{i} P(x_i) \log \frac{P(x_i)}{Q(x_i)}$$

It represents the *extra* number of bits required to encode samples from $P$ using a code optimized for $Q$ rather than the optimal code for $P$.

**Key Properties:**
- **Gibbs' Inequality (Non-negativity):** $D_{KL}(P \parallel Q) \ge 0$. This is proven using Jensen's Inequality on the strictly concave logarithm function.
- **Asymmetry:** $D_{KL}(P \parallel Q) \neq D_{KL}(Q \parallel P)$. It is a "directed" divergence, not a true distance metric, and does not satisfy the triangle inequality.
- **The Zero-Probability Problem:** If there exists an $x$ where $Q(x) = 0$ but $P(x) > 0$, the KL divergence goes to infinity. This is mathematically fragile for empirical data.

## 5. Jensen-Shannon (JS) Divergence

Because KL divergence is asymmetric and severely punished by zero probabilities, the Jensen-Shannon Divergence was introduced as a smoothed, symmetric alternative [5].

It computes the KL divergence of both $P$ and $Q$ to an average mixture distribution $M = \frac{1}{2}(P + Q)$:

$$JSD(P \parallel Q) = \frac{1}{2} D_{KL}(P \parallel M) + \frac{1}{2} D_{KL}(Q \parallel M)$$

**Key Properties:**
- **Symmetry:** $JSD(P \parallel Q) = JSD(Q \parallel P)$.
- **Boundedness:** When using base-2 logarithms, $0 \le JSD(P \parallel Q) \le 1$.
- **Robustness:** Because the mixture distribution $M$ guarantees that $M(x) > 0$ whenever either $P(x) > 0$ or $Q(x) > 0$, the division-by-zero problem of KL divergence is entirely eliminated.

### 5.1 Comparison: JS Divergence vs Wasserstein Distance
When measuring the disagreement between two distributions, JS Divergence is the primary workhorse. However, it is essential to compare this against the Wasserstein Distance (Earth Mover's Distance):

| Metric | Mechanism | Handles Zero-Probabilities? | Awareness of Metric Space? |
| --- | --- | --- | --- |
| **JS Divergence** | Compares probabilities bin-by-bin via entropy. | Yes, mathematically stable. | No. It treats all classes as equally different (Class 1 and Class 2 are just separate bins). |
| **Wasserstein Distance** | Measures the "cost" of transporting probability mass from one distribution to another. | Yes. | Yes. It requires a distance matrix between classes (e.g., Depression is closer to Anxiety than to Schizophrenia). |

**Why JSD is typically preferred:** While Wasserstein distance is theoretically powerful for semantics, calculating it requires defining a ground-truth distance matrix between all possible textual classes. JS Divergence is mathematically stable, bounded, and operates directly on the output probabilities without requiring external assumptions about inter-class distances.

## 6. Mutual Information

Mutual Information measures the reduction in uncertainty about one random variable after observing another [2].

$$I(X;Y) = H(X) - H(X|Y) = H(Y) - H(Y|X) = H(X) + H(Y) - H(X,Y)$$

Equivalently, it can be defined using KL divergence to measure how far the joint distribution $P(X,Y)$ is from the assumption of independence $P(X)P(Y)$:
$$I(X;Y) = D_{KL}(P(X,Y) \parallel P(X)P(Y))$$

### 6.1 Comparison: Mutual Information vs Pearson Correlation
When establishing predictive value, MI is far superior to standard correlation metrics:

| Metric | Mechanism | Captures Non-Linear Relationships? | Applies to Categorical Variables? |
| --- | --- | --- | --- |
| **Pearson Correlation ($r$)** | Measures linear dependence between two continuous variables. | No. If $Y = X^2$, $r = 0$. | No. |
| **Mutual Information ($I(X;Y)$)** | Measures general statistical dependence via entropy reduction. | Yes. It detects complex, non-linear dependencies flawlessly. | Yes. |

**Interpretation for reliability estimation:** 
Let $E \in \{0, 1\}$ be the binary event of a model prediction error, and $JSD$ be the continuous geometric disagreement score. Mutual information $I(JSD ; \text{Error})$ quantifies non-linear dependence between geometric evidence and epistemic failure.

Mutual Information is primarily a **dataset-level analysis**, while disagreement features are **sample-level quantities**. $I(JSD ; \text{Error})$ is computed over an entire dataset to prove that $JSD$ is a worthwhile feature; you cannot compute it meaningfully for one single sample during inference.

## 7. Conditional Entropy

Conditional Entropy measures the remaining uncertainty about a random variable $Y$ after observing another random variable $X$.

$$H(Y|X) = -\sum_{x \in X} p(x) \sum_{y \in Y} p(y|x) \log p(y|x) = -\sum_{x \in X, y \in Y} p(x,y) \log \frac{p(x,y)}{p(x)}$$

**Interpretation:**
Suppose we are examining the local semantic neighborhood of a test representation. If the empirical neighborhood class distribution is highly uniform, we might ask: *How uncertain is the true class label given the local neighborhood?* 

This is fundamentally conditional entropy. If the representation is surrounded by 50% "Depression" samples and 50% "Anxiety" samples, $H(\text{Class} | \text{Neighborhood}) = 1$ bit (maximum uncertainty for binary classification). If the neighborhood is 100% "Depression", $H(\text{Class} | \text{Neighborhood}) = 0$. Conditional entropy formally quantifies the intrinsic ambiguity residing in specific local regions of the representation space.

## 8. Distribution Shift

In real-world deployments, the distribution of data encountered during inference ($P_{test}$) often differs from the training distribution ($P_{train}$). Softmax confidence scores are notoriously fragile under shift, making geometric evaluation critical.

Information-theoretic tools detect and quantify this shift across three primary modes:

1. **Covariate Shift ($P_{test}(X) \neq P_{train}(X)$):** The input distribution changes, but the labeling rule remains the same ($P_{test}(Y|X) = P_{train}(Y|X)$). 
   - *NLP Example:* A depression classifier trained on Reddit posts is deployed on formal clinical notes. 
2. **Prior Probability Shift ($P_{test}(Y) \neq P_{train}(Y)$):** The label distribution changes (e.g., base rates shift).
   - *NLP Example:* A sentiment classifier trained on a balanced dataset is deployed during a product crisis where 95% of reviews are negative.
3. **Concept Drift ($P_{test}(Y|X) \neq P_{train}(Y|X)$):** The fundamental relationship between inputs and outputs changes.
   - *NLP Example:* Language evolution. The word "sick" shifting from meaning "ill" to meaning "excellent".

## 9. Constructing Neighborhood Distributions

In neighborhood-based disagreement estimation, we rely on the empirical "neighborhood distribution" of classes, denoted as $Q_{kNN}$. But how is this distribution practically constructed from a discrete set of retrieved neighbors? 

### Approach A: Raw Frequency (Unweighted)
The simplest construction is a normalized histogram of the labels in the top-$k$ set.
For example, if $k=5$ and the neighbors have labels: [Depression, Depression, Anxiety, Anxiety, Anxiety].
$$Q_{kNN} = \left[\frac{2}{5}, \frac{3}{5}\right] = [0.4, 0.6]$$

### Approach B: Similarity-Weighted 
In high-dimensional representation space, weighting the votes by geometric similarity ensures closer neighbors exert more influence on the empirical probability [7].

Let $d_i$ be the cosine distance to the $i$-th neighbor, and $w_i = \exp(-d_i / T)$ be a temperature-scaled similarity weight. The distribution becomes:
$$Q_{kNN}(c) = \frac{\sum_{i=1}^{k} \mathbb{1}(y_i = c) \cdot w_i}{\sum_{i=1}^{k} w_i}$$

This converts discrete geometric neighbors into a smooth, continuous probability distribution $Q_{kNN}$ that can be formally compared against the model's softmax output $P_{model}$.

### 9.1 Multi-Class Sparsity and Label Smoothing (The "Zero Probability" Problem)
If a specific class $c$ never appears in the $k$ neighbors, its empirical probability $Q_{kNN}(c) = 0$. 
When comparing $P_{model}$ against $Q_{kNN}$ via information-theoretic metrics, hard zeroes create severe mathematical fragility (infinite KL divergence). While JS Divergence mitigates this via the mixture distribution $M = \frac{1}{2}(P+Q)$, pure zeroes in $Q$ still lead to extreme boundary behaviors in the entropy calculations.

**The Solution:** 
To properly construct $Q_{kNN}$, we must apply **Laplace Smoothing** or add a weak **Dirichlet Prior**:
$$Q_{kNN}(c) = \frac{\text{Count}(c) + \alpha}{k + C \alpha}$$
where $\alpha$ is a small smoothing parameter (e.g., $\alpha = 0.1$) and $C$ is the total number of classes. This guarantees that $Q_{kNN}$ retains full support across the entire class manifold, ensuring the Distributional Disagreement computations are robust in highly imbalanced setups.
