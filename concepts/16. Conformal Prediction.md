# Conformal Prediction

These are comprehensive study notes. Every factual claim is cited. References focus on the mathematical guarantees of conformal prediction and its intersection with deep learning reliability.

While Note 15 discussed the *heuristic* approach to abstention (tuning a threshold to hit a desired risk rate), **Conformal Prediction (CP)** provides a mathematically rigorous alternative. CP generates prediction sets that are theoretically guaranteed to contain the true label with a user-specified probability (e.g., $95\%$), regardless of the underlying model or data distribution [1][2].

### Conceptual Hierarchy

```text
Heuristic Thresholding
          ↓
  Conformal Prediction
          ↓
```

## 1. The Mathematical Guarantee

Given a user-specified error rate $\alpha \in (0, 1)$ (e.g., $\alpha = 0.05$ for $95\%$ confidence), Conformal Prediction outputs a **Prediction Set** $\mathcal{C}(x) \subseteq \mathcal{Y}$ for a new test input $x_{test}$.

The fundamental theorem of CP guarantees **Marginal Coverage**:
$$P(y_{test} \in \mathcal{C}(x_{test})) \geq 1 - \alpha$$

This holds true under only one assumption: the calibration data and test data must be **exchangeable** (typically satisfied if they are i.i.d.). It does *not* require the underlying model to be accurate, well-calibrated, or linear. If the model is completely random, CP still works—it will simply output the entire label space $\mathcal{Y}$ to maintain the $95\%$ guarantee.

## 2. Conformal Risk Control (CRC)

Standard CP focuses strictly on *set prediction* (guaranteeing the true label is in the set). However, modern reliability literature is shifting towards **Conformal Risk Control (CRC)** [7]. 

CRC extends CP guarantees to *any* monotonic risk function, not just miscoverage. Instead of guaranteeing $P(y \in \mathcal{C}) \ge 1-\alpha$, CRC guarantees that the expected value of an arbitrary loss function $L$ is bounded by a user-specified threshold $\lambda$:
$$\mathbb{E}[L(\mathcal{C}(X), Y)] \le \lambda$$

**Relevance to risk control:**
Conformal risk control is fundamentally a framework to **control error risk**, rather than predict label sets. If we define our loss function as the cost of making an incorrect clinical diagnosis without human review, CRC provides the exact mathematics needed to tune a $JSD$ threshold so that the expected clinical risk never exceeds a hospital's mandated safety limit.

## 3. The Nonconformity Score

The engine of Conformal Prediction is the **Nonconformity Score function**, $s(x, y)$.

$s(x, y)$ measures how "unusual" or "bad" the pairing of input $x$ and label $y$ is, according to the model. Higher scores mean the pairing is highly nonconforming.

### 2.1 Comparison: Typical Nonconformity Scores

| Method | Nonconformity Score $s(x, y)$ | Implication for CP |
| --- | --- | --- |
| **Softmax (Adaptive)** | $1 - \hat{p}_y(x)$ | The standard baseline. Fails if the model is overconfident on OOD data. |
| **Distance to Centroid** | $\| \text{Embed}(x) - \mu_y \|_2$ | Better geometric grounding, but assumes isotropic clusters (see Note 12). |
| **DkNN [4]** | Fraction of $k$-NN that *do not* belong to class $y$. | Explicitly incorporates geometric density. |
| **JSD Nonconformity** | $JSD(P_{model} \parallel Q_{kNN})$ assuming $y$ is the prediction. | Captures deep distributional disagreement as a measure of nonconformity. |

## 4. The Split Conformal Algorithm

Standard CP requires retraining the model for every new test point, which is impossible for Large Language Models. Modern applications use **Split Conformal Prediction** (or Inductive CP) [3].

### The 4-Step Process:
1. **Split:** Divide the training data into a Training Set and a Calibration Set.
2. **Train:** Train the model $f(x)$ on the Training Set.
3. **Calibrate:** For every sample $i$ in the Calibration Set, compute its true nonconformity score $s_i = s(x_i, y_i)$.
4. **Quantile:** Calculate the $\hat{q}$ value, which is the $\frac{\lceil (n+1)(1-\alpha) \rceil}{n}$ empirical quantile of the calibration scores.

### Inference:
For a new test point $x_{test}$, construct the prediction set by including every possible label $y \in \mathcal{Y}$ that satisfies:
$$\mathcal{C}(x_{test}) = \{ y \in \mathcal{Y} : s(x_{test}, y) \leq \hat{q} \}$$

**Relevance to geometric scores:**
If $JSD$ is used as the nonconformity score, the set $\mathcal{C}$ will automatically expand to include multiple labels (or abstain entirely) when the local geometric neighborhood heavily contradicts the model.

## 5. Marginal vs. Conditional Coverage

A major limitation of standard CP is that the $1-\alpha$ guarantee is **Marginal**.

### 4.1 The Difference
- **Marginal Coverage:** Over 1,000 predictions, exactly 950 will contain the true label. However, the 50 errors might all occur on a specific minority subgroup (e.g., AAVE text).
- **Conditional Coverage:** $P(y \in \mathcal{C}(x) | X=x) \geq 1 - \alpha$. The guarantee holds for *every specific input*.

True conditional coverage is mathematically impossible to guarantee for continuous distributions without infinite data [6]. 

### 5.2 Group-Conditional Coverage and Mondrian CP
To mitigate this in clinical settings, we use **Group-Conditional Coverage**. Instead of one global quantile $\hat{q}$, we partition the input space into disjoint groups and compute separate quantiles $\hat{q}_g$ for specific demographic or linguistic subgroups. 

The canonical algorithm for achieving this is **Mondrian Conformal Prediction** [8]. By applying the standard CP procedure independently to each predefined Mondrian category $c$, the algorithm calculates a group-specific threshold $\hat{q}_c$:
$$\mathcal{C}(x_{test}) = \{ y \in \mathcal{Y} : s(x_{test}, y) \leq \hat{q}_c \}$$
where $\hat{q}_c$ is the $\frac{\lceil (n_c+1)(1-\alpha) \rceil}{n_c}$ quantile of the calibration scores *only for those samples belonging to group* $c$.

By doing this, we ensure that the validity guarantee holds not just globally, but identically across all selected subpopulations. In a clinical setting, applying Mondrian CP prevents the system from abstaining systematically on underrepresented dialects or minority clinical language.

### 5.3 Comparison: Coverage Guarantees

| Guarantee Type | Mathematical Definition | Clinical Consequence |
| --- | --- | --- |
| **Marginal** | $P(y \in \mathcal{C}(x)) \ge 1-\alpha$ | The easiest to achieve. The model is 95% safe overall, but might be 100% wrong on Hispanic patients. |
| **Conditional** | $P(y \in \mathcal{C}(x) | X=x) \ge 1-\alpha$ | Theoretically impossible to guarantee in continuous spaces without infinite data. |
| **Mondrian / Group** | $P(y \in \mathcal{C}(x) | X \in \text{Group}_c) \ge 1-\alpha$ | The pragmatic middle ground. Ensures 95% safety holds equally across predefined demographic buckets. |

## 6. Adaptive Prediction Sets (APS)

In multi-class NLP problems, standard CP might output sets of size 0 (abstention) or size 1 (confident prediction). However, sometimes it outputs sets of size 2 or 3 (e.g., `["Depression", "Anxiety"]`).

**Adaptive Prediction Sets (APS)** [5] is a CP variant specifically designed to rank the probabilities and add labels to the set until the cumulative probability exceeds the calibration threshold. For multi-class clinical triage, APS combined with geometric $Q_{kNN}$ weighting is a promising direction for producing safe, bounded differential diagnoses.

## 7. Conformal Prediction Under Shift

The foundational assumption of all CP math is that the calibration set and the test point are **exchangeable**. 

However, CP for NLP is explicitly motivated by the fact that language models face **Out-Of-Distribution (OOD)** inputs, Concept Drift, and Covariate Shift in production. When exchangeability is violated, standard CP guarantees fail. 

> [!WARNING]
> **The Exchangeability Assumption**
> The mathematical guarantees of Conformal Prediction (and by extension CRC and Mondrian CP) are absolutely contingent on the assumption of **exchangeability** between the calibration set and the test set. 
> 
> A common misconception is: `JSD -> CP -> Guaranteed Safety`. This is **false**. If the production data undergoes a distributional shift (e.g., a hospital switches its EMR software, altering the language of clinical notes), exchangeability is broken and the marginal coverage guarantees are immediately voided. A nonconformity score — however well designed — cannot fix broken exchangeability on its own.

To maintain validity under distribution shift, advanced variants must be used:

| Shift Algorithm | Mechanism | Best Use Case |
| --- | --- | --- |
| **Adaptive Conformal Inference (ACI)** | Dynamically updates the threshold $\alpha_t$ over time based on the recent error rate [9]. If it errors too much, it forces $\alpha$ lower, making the prediction sets larger (safer). | Gradual Concept Drift. ACI self-corrects without needing to recalculate nonconformity scores. |
| **Weighted Conformal Prediction** | Reweights calibration samples using covariate shift density ratios: $w(x) = p_{test}(x) / p_{train}(x)$. | Sudden Covariate Shift. If we deploy a model trained on Reddit onto Twitter data, we upweight the calibration samples that look most like Twitter. |
| **Ensemble Batch Prediction Intervals (EnbPI)** | Updates nonconformity scores in sequential batches without retraining the underlying model [10]. | Time-Series Data. Highly effective for streaming clinical note ingestion. |

While standard CP provides the mathematical baseline for abstention frameworks, deploying it in a live clinical environment will mandate awareness of these shift-robust adaptations.
