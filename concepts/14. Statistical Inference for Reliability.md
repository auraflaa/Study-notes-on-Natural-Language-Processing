# Statistical Inference for Reliability

These are comprehensive study notes. Every factual claim is cited. References focus on applied regression analysis, hypothesis testing, and rigorous statistical evaluation of predictive features.

Evaluating geometric reliability signals is entirely a statistical inference problem. We are not building a new classification model; we are evaluating whether a set of geometric and information-theoretic features ($JSD$, $H(Q_{kNN})$) provide statistically significant predictive power for detecting a model's epistemic failure. 

This note outlines the rigorous statistical framework required to test such a hypothesis and systematically justifies the choice of statistical methods over their alternatives.

### Conceptual Hierarchy

```text
The Binary Outcome (Error=1, Correct=0)
          ↓
  Logistic Regression vs Alternatives
          ↓
  Nested Model Comparison
  (Likelihood Ratio Test vs Wald/Score)
          ↓
  Goodness of Fit (McFadden's Pseudo-R²)
          ↓
  Non-Linearity & Interactions
          ↓
  Pathologies (Complete Separation)
```

## 1. The Statistical Objective

The core objective is to predict whether a pre-trained base classifier's prediction on a specific sample is an error. We are mapping the epistemic uncertainty of the deep neural network to a discrete, observable event: a classification failure.

Let $y \in \{1, 2, \dots, C\}$ be the true ground-truth label.
Let $\hat{y} = \arg\max P_{model}$ be the model's predicted class.

We define the binary failure event $E_i$ for sample $i$ as:
$$E_i = \begin{cases} 
1 & \text{if } \hat{y}_i \neq y_i \\
0 & \text{if } \hat{y}_i = y_i 
\end{cases}$$

Our goal is to model the probability of an error occurring, $P(E = 1 | X)$, using a set of covariates $X$. The covariates include baseline model confidence ($p_{max}$) and geometric disagreement features (e.g., $JSD(P_{model} \parallel Q_{kNN})$).

## 2. Binary Logistic Regression

Because our dependent variable $E$ is strictly binary, Ordinary Least Squares (OLS) regression is mathematically invalid (it would predict probabilities $<0$ or $>1$ and violate the assumption of homoscedasticity). We must use a classification model.

### 2.1 Comparison: Classification Models for Inference
Why choose Logistic Regression over a modern machine learning classifier?

| Model | Mechanism | Interpretability | Formal Inference (p-values)? | Suitability for Reliability Inference |
| --- | --- | --- | --- | --- |
| **Random Forest / XGBoost** | Non-linear ensemble of decision trees. | Feature Importance only. | No. Cannot formally prove specific relationships. | **Poor.** Black-box mapping defeats the purpose of proving *why* it works. |
| **Support Vector Machine (SVM)** | Maximizes margin between classes in higher dimensions. | Distance to hyperplane. | No. Outputs unbounded scores, not probabilities. | **Poor.** Lacks probabilistic grounding. |
| **Probit Regression** | GLM with Normal cumulative distribution link. | Coefficients represent $Z$-scores. | Yes. | **Good.** But log-odds (Logistic) are easier to interpret. |
| **Logistic Regression** | GLM with Logistic (logit) link function. | Coefficients map directly to Log-Odds ratios. | **Yes.** Maximum Likelihood Estimation yields standard errors. | **Excellent.** The scientific gold standard for binary inference. |

The logistic regression model models the log-odds (logit) as a linear combination of features:
$$\log\left(\frac{P(E=1 | X)}{1 - P(E=1 | X)}\right) = \beta_0 + \beta_1 X_1 + \dots + \beta_k X_k$$

**Why this matters:**
We will fit this model using Maximum Likelihood Estimation (MLE). If the estimated coefficient $\hat{\beta}_k$ for a geometric feature (like JS Divergence) is significantly non-zero (with $p < 0.05$ or $p < 0.01$), it provides evidence that the feature contributes predictive information regarding model failure.

## 3. Nested Model Comparison

To prove that geometric features *add value* beyond what standard Softmax outputs already provide, we must use **Nested Models** [4]. A model is "nested" within another if it contains a strict subset of the other's predictors. 

**Model A (The Baseline Null Model):** Predicts failure using only stated confidence.
$$\text{logit}(P) = \beta_0 + \beta_1(p_{max}) + \beta_2(H(P_{model}))$$

**Model B (The Geometric Alternative Model):** Adds geometric disagreement.
$$\text{logit}(P) = \beta_0 + \beta_1(p_{max}) + \beta_2(H(P_{model})) + \beta_3(JSD) + \beta_4(H(Q_{kNN}))$$

### 3.1 Comparison: Hypothesis Testing for Parameters
How do we mathematically prove Model B is superior to Model A?

| Test | Mechanism | Computational Cost | Robustness in Small/Complex Samples |
| --- | --- | --- | --- |
| **Wald Test** | Computes $(\hat{\beta} / SE)^2$ for a single parameter. | Very Low (computed directly from MLE). | **Lowest.** Prone to Hauck-Donner effect (false negatives) if separation occurs. |
| **Score Test (Lagrange)** | Computes gradient of likelihood at the null value. | Low. | **Moderate.** Doesn't require fitting the full complex model. |
| **Likelihood Ratio Test (LRT)** | Compares the total maximized likelihoods of Model A vs Model B. | High (must fit both models separately). | **Highest.** The absolute gold standard for nested model comparison. |

**The LRT Calculation:**
Let $L_A$ and $L_B$ be the maximum likelihoods. The test statistic is:
$$\lambda = -2 \log \left( \frac{L_A}{L_B} \right) = 2(\log L_B - \log L_A)$$
$\lambda$ follows a Chi-squared ($\chi^2$) distribution. If the resulting $p$-value is very small, we reject the null hypothesis that $\beta_3 = \beta_4 = 0$.

## 4. Goodness of Fit: Pseudo-$R^2$

In standard OLS regression, $R^2$ represents the fraction of variance explained by the model. Logistic regression does not have a true variance-based $R^2$. Instead, we use pseudo-$R^2$ metrics [7].

### 4.1 Comparison: Pseudo-$R^2$ Metrics
Not all $R^2$ metrics are created equal in the GLM world.

| Metric | Mechanism | Maximum Value | Reliability Inference Use Case |
| --- | --- | --- | --- |
| **OLS $R^2$** | Sum of Squared Errors vs Total Variance. | $1.0$ | Invalid for binary outcomes. |
| **Cox-Snell $R^2$** | Geometric mean of likelihood improvements. | Always $< 1.0$ (often maxes at 0.75). | Misleading due to capped upper bound. |
| **McFadden's $R^2$** | Log-likelihood of fitted model vs intercept-only model. | $1.0$ (practically $\approx 0.5$) | **The Industry Standard.** Highly penalizes weak models. |

## 5. Beyond p-values: Effect Size and Confidence Intervals

Modern machine learning reviewers increasingly distrust bare $p$-values ($p < 0.05$) due to the ease of "p-hacking" and the fact that in massive NLP datasets, even trivial differences become statistically significant. A rigorous evaluation requires proving that the signal is practically meaningful, not just statistically detectable.

### 5.1 Effect Size

Effect size measures the *magnitude* of the relationship between the reliability signal and the error outcome. 

- **Odds Ratios ($OR$):** Derived directly from the exponentiated logistic regression coefficients ($e^{\beta}$). An $OR = 2.5$ for $JSD$ means that for every 1-unit increase in $JSD$, the odds of the model making an error increase by 2.5 times.
- **Cliff's Delta ($d$):** A non-parametric effect size measure quantifying how often the $JSD$ of an Error is higher than the $JSD$ of a Correct Prediction. Unlike Cohen's $d$, it does not assume normality, making it ideal for bounded metrics like $JSD$.

### 5.2 Confidence Intervals

Point estimates for evaluation metrics (AUROC, AUPRC, AURC) are insufficient. To prove a reliability estimator is robust, we must construct **$95\%$ Confidence Intervals**.

Because reliability distributions are highly non-normal and heavily skewed (e.g., AUPRC-Error in a highly accurate model), parametric CIs fail. We must use **Non-Parametric Bootstrap Resampling**. By resampling the test set with replacement 1,000 times, computing the AUROC on each bootstrap sample, and taking the $2.5^{th}$ and $97.5^{th}$ percentiles, we generate distribution-free confidence bounds that reviewers will trust.

$$R_{McFadden}^2 = 1 - \frac{\log L_{fitted}}{\log L_{null}}$$

**Interpretation:**
McFadden's $R^2$ values are extremely conservative. A score of $0.2 - 0.4$ represents an excellent fit. Here, the absolute magnitude matters less than the $\Delta R^2$ between Model A and Model B, which tells us exactly how much additional predictive power the geometry provides.

## 6. Interaction Terms and Non-Linearity

### 5.1 Interaction Terms
It is highly likely that the relationship between $p_{max}$ and $JSD$ is not purely additive. If $p_{max} = 0.99$ (extreme confidence) but $JSD$ is high (massive geometric disagreement), this specific *combination* strongly implies a catastrophic failure. 

To model this, regressions must include **Interaction Terms**:
$$\text{logit}(P) = \beta_0 + \beta_1(p_{max}) + \beta_2(JSD) + \beta_3(p_{max} \times JSD)$$
A significant $\beta_3$ coefficient proves that the *disagreement* between the two metrics specifically predicts failure.

### 5.2 Comparison: Modeling Non-Linear Calibration
True model confidence curves are notoriously non-linear (e.g., sigmoidal over-confidence). How do we account for this before adding geometric features?

| Transformation | Mechanism | Risk |
| --- | --- | --- |
| **Strictly Linear** | Uses raw $p_{max}$ directly. | Massively underfits true calibration curves. |
| **Polynomials** | Adds $(p_{max})^2, (p_{max})^3$. | Highly unstable at the boundaries ($p \approx 0$ or $1$). |
| **Restricted Cubic Splines (B-splines)** | Fits piecewise cubic polynomials with continuous derivatives, restricted to be linear at tails. | **Optimal.** Flexibly captures complex calibration curves without tail instability [3]. |

## 7. A Pathology: Complete Separation

When evaluating extremely strong predictors, a pathology known as **Complete Separation** can occur [8].

### 6.1 Comparison: Logistic Regression Pathologies

| Pathology | Cause | Effect | Solution |
| --- | --- | --- | --- |
| **Multicollinearity** | Highly correlated features (e.g., $JSD$ and $D_{KL}$). | Inflated Standard Errors. Wide Confidence Intervals. | Drop redundant features or use Ridge regularization. |
| **Overdispersion** | Variance of the data is higher than the binomial model assumes. | Deflated p-values (false positives). | Not typically an issue for strict binary (Bernoulli) data. |
| **Complete Separation** | A feature perfectly predicts the outcome (e.g., all samples with $JSD > 0.8$ are errors). | Likelihood does not converge. $\beta \rightarrow \infty$. | **Firth's Penalized Likelihood.** |

**Implications:**
If the geometric features are *too good*, standard MLE will fail to converge and throw a `PerfectSeparationError`. If this occurs, it is actually a massive success for the hypothesis, but requires switching to **Firth's Penalized Likelihood** (which adds a Jeffreys prior penalty) to compute finite coefficients and valid $p$-values.
