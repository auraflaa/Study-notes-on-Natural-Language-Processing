# Out-of-Distribution Detection & Semantic Rarity

Comprehensive study notes on OOD detection, semantic rarity, and energy-based methods. All claims cited. Sources expanded to cover the full progression from MSP baseline through ODIN, Mahalanobis distance, energy-based methods, and text-specific approaches.

Out-of-distribution (OOD) detection is the problem of identifying when a model is receiving inputs that differ so substantially from its training distribution that its predictions cannot be trusted. 

For mental health classification systems, this is not just a research concern — it is a clinical safety requirement. A model that expresses maximum confidence on a post it cannot actually interpret may trigger or suppress an intervention that determines whether someone receives help [1][2][3][4].

---

## 1. The OOD Problem: Formal Statement and Taxonomy

### 1.1 Formal Setup

Let $`\mathcal{X}`$ be the input space (all possible text inputs) and $`\mathcal{Y} = \{1, \ldots, C\}`$ the label space. A classifier $`f: \mathcal{X} \to \mathcal{Y}`$ is trained on data drawn i.i.d. from $`P_{in}(X, Y)`$ — the **in-distribution**.

At deployment, inputs may come from $`P_{out}(X)`$ — a different marginal distribution over $`\mathcal{X}`$, potentially without any notion of a corresponding $`Y`$ in $`\mathcal{Y}`$.

**OOD detection** is the problem of building a scoring function:

```math
s: \mathcal{X} \to \mathbb{R}
```

such that $`s(x)`$ is high for $`x \sim P_{in}`$ and low for $`x \sim P_{out}`$, with a threshold $`\delta`$ applied:

```math
g(x) = \begin{cases} \text{in-distribution} & s(x) \geq \delta \\ \text{out-of-distribution} & s(x) < \delta \end{cases}
```

**The fundamental difficulty:** $`f`$ was trained to discriminate between classes within $`P_{in}`$. It has no loss signal for recognising $`P_{out}`$ — it was never trained on OOD examples. Yet it will produce softmax probability vectors for any input in $`\mathcal{X}`$, regardless of how anomalous [1].

### 1.2 Taxonomy of Distribution Shifts

Shifts are not binary (in or out) — they exist on a spectrum with qualitatively different properties:

**Near-OOD is the most dangerous case** in mental health NLP. An input that uses clinical vocabulary in a different register (e.g., a medical research abstract about depression vs. a Reddit post about depression) may receive the same high-confidence "Depression" prediction, but the features informing that prediction are entirely different.

### 1.3 Mental Health-Specific OOD Types

| Shift Type | Concrete Example | Why Dangerous |
| :--- | :--- | :--- |
| **Sarcasm/Irony** | "yeah I'm totally fine 🙂" | Model sees negative content, predicts crisis — but user is being sarcastic |
| **Fiction/Discussion** | "my character in this story is suicidal" | Fictional crisis language triggers real crisis flags |
| **Medical/Academic** | "depression incidence in clinical populations is..." | Academic discourse classified as personal depression |
| **Code-switching** | "je suis très déprimé" (French) | General BERT has no French training for mental health domain |
| **Historical** | Posts from 2010 vs. 2024 cultural references | Linguistic drift in internet slang not captured in training |
| **Platform shift** | Twitter → Reddit → clinical notes | Each platform has distinct linguistic register |

## 2. The Maximum Softmax Probability Baseline

### 2.1 The Hendrycks & Gimpel Baseline (2017)

Hendrycks and Gimpel [1] established the first systematic, comprehensive OOD detection baseline for neural networks. Their central observation:

> *"Correctly classified examples tend to have greater maximum softmax probabilities than erroneously classified and out-of-distribution examples."*

**The MSP score:**
```math
s_{MSP}(x) = \max_{j \in \{1,\ldots,C\}} \text{softmax}(f(x))_j = \max_j \hat{p}_j
```

**Threshold detector:**
```math
g(x) = \begin{cases} \text{in} & \max_j \hat{p}_j \geq \delta \\ \text{out} & \max_j \hat{p}_j < \delta \end{cases}
```

### 2.2 Worked Numerical Example

Consider a 4-class mental health classifier with threshold $`\delta = 0.7`$:

**In-distribution input:** "I've been feeling really hopeless lately, nothing seems worth it anymore"
```
z = [3.2, 0.4, -0.1, 0.9]
p̂ = softmax(z) = [0.891, 0.054, 0.033, 0.022]
max p̂ = 0.891 ≥ 0.7 → Classified as IN-DISTRIBUTION ✓
```

**OOD input (medical abstract):** "Prevalence of major depressive disorder in adults: a meta-analysis"
```
z = [2.1, 0.8, 0.2, 0.7]   ← smaller spread, moderate logits
p̂ = softmax(z) = [0.621, 0.166, 0.091, 0.122]
max p̂ = 0.621 < 0.7 → Correctly flagged as OOD ✓
```

**OOD input that fools MSP:** "LOL I'm so depressed that my favourite show got cancelled 😭"
```
z = [2.8, 0.5, -0.2, 1.1]   ← casual language activates depression features strongly
p̂ = softmax(z) = [0.832, 0.074, 0.037, 0.137]
max p̂ = 0.832 ≥ 0.7 → INCORRECTLY classified as IN-DISTRIBUTION ✗
```

This third case is the failure mode — colloquial use of "depressed" in a non-clinical context triggers high confidence.

### 2.3 Results and Limitations [1]

**Benchmark results:** On 20 Newsgroups with unknown-class OOD:
- MSP AUROC: ~0.88
- Baseline FPR95: ~45%

**Failure modes:**
1. **Overconfident OOD:** Neural networks, as shown by Nguyen et al. [8], can produce near-unity softmax confidence on completely unrecognisable inputs. The softmax always normalises to a distribution — it cannot output "I don't know."
2. **Near-OOD collapse:** When OOD inputs partially overlap with in-distribution features (e.g., casual vs. clinical depression language), MSP cannot distinguish them — both produce high softmax outputs.
3. **The normalisation trap:** Suppose a 10-class model sees a random noise input. Even if no class is appropriate, the softmax redistributes all probability mass to the class whose weights happen to align with the noise features. This is a structural failure of softmax normalisation.

## 3. ODIN: Temperature and Input Perturbation

### 3.1 Theoretical Motivation

Liang et al. [3] observed that the gap between ID and OOD softmax scores, while small at $`T=1`$, can be amplified by:
1. Applying high temperature ($`T \gg 1`$) to compress differences between classes
2. Making small gradient-guided perturbations to the input to maximally separate ID from OOD

### 3.2 The Temperature Mechanism

At high temperature, the softmax becomes nearly uniform for both ID and OOD inputs — but ID inputs retain slightly higher maximum probabilities because their logits have stronger internal structure (one class logit dominates). The gap is amplified in relative terms.

Formally: let $`z^{ID}`$ and $`z^{OOD}`$ be logit vectors for ID and OOD inputs. Assume $`z^{ID}`$ has a single dominant logit $`z^{ID}_1 \gg z^{ID}_j \; \forall j \neq 1`$, while $`z^{OOD}`$ is more uniform.

At $`T=1`$: $`\max_j \hat{p}^{ID}_j \approx 0.9`$, $`\max_j \hat{p}^{OOD}_j \approx 0.6`$ → gap = 0.3

At $`T=100`$: both distributions flatten, but $`\max_j \hat{p}^{ID}_j > \max_j \hat{p}^{OOD}_j`$ with better separation relative to variance.

### 3.3 The Input Perturbation Mechanism

For a given input $`x`$, compute the gradient of the maximum softmax probability with respect to the **input** (not the model parameters):

```math
\tilde{x} = x - \varepsilon \cdot \text{sign}\left(\nabla_x \max_j \hat{p}_j(x; T)\right)
```

This perturbs $`x`$ in the direction that **increases** the ID confidence score. ID inputs move more than OOD inputs in their own confidence direction, widening the gap.

**Why this works for ID inputs:** An in-distribution input is near a region of high density in the model's learned feature space. A small gradient step moves it further into the high-density region — the model becomes even more confident.

**Why this works differently for OOD inputs:** An OOD input is far from any learned class cluster. The gradient step may move it toward a class cluster in pixel/token space — but the representation at the penultimate layer changes less dramatically, so the confidence boost is smaller.

### 3.4 The Combined ODIN Score

```math
s_{ODIN}(x) = \max_j \text{softmax}(\tilde{x}; T)_j
```

where $`\tilde{x}`$ is the perturbed input and $`T`$ is the temperature hyperparameter.

### 3.5 Hyperparameter Tuning and Practical Issues

**Tuning requires OOD validation data:** $`T`$ and $`\varepsilon`$ must be chosen on a held-out OOD dataset. For $`T`$: typically $`T \in \{1, 10, 100, 1000\}`$. For $`\varepsilon`$: typically $`\varepsilon \in \{0.0005, 0.001, 0.0014, 0.002, 0.0024, 0.005, 0.01, 0.05, 0.1, 0.2\}`$.

**Problem:** In clinical deployment, suitable OOD validation data may not exist or may be unethical to collect (requiring crisis posts from untreated individuals).

**Text perturbation challenge:** For text inputs (unlike images), the input is discrete — gradient steps produce continuous embedding perturbations, not actual text perturbations. ODIN must operate in the **embedding space** of the tokeniser, not on discrete tokens. This limits the technique's applicability to text OOD detection.

### 3.6 Results [3]

On CIFAR-10 vs. various OOD datasets:
- MSP FPR95: 51.5%
- ODIN (temperature only) FPR95: ~40%
- ODIN (temperature + perturbation) FPR95: **25–30%**

A significant improvement, but the text-domain limitation is important.

## 4. Energy-Based OOD Detection

### 4.1 The Energy-Based Model Framework

Liu et al. [2] grounded OOD detection in the theory of **energy-based models (EBMs)**. An EBM assigns an energy $`E(x)`$ to each input, with lower energy indicating higher probability density under the model's distribution.

The connection to neural classifiers: for a neural network with logits $`z(x) = (z_1(x), \ldots, z_C(x))`$, define the **free energy**:

```math
E(x; T) = -T \log \sum_{k=1}^C e^{z_k(x)/T}
```

This is the **negative log-partition function** of the softmax distribution at temperature $`T`$.

**Key theoretical property [2]:** Under a probabilistic model where $`p(x, y) \propto e^{z_y(x)/T}`$, the marginal density of inputs is:

```math
p(x) \propto \sum_y p(x, y) = \sum_y e^{z_y(x)/T} = e^{-E(x;T)/T}
```

So lower energy = higher marginal density = more likely to be in-distribution.

### 4.2 The Energy Score in Practice

**Energy score for OOD detection:** Use $`-E(x; T)`$ (higher = more in-distribution):

```math
s_{energy}(x) = -E(x; T) = T \log \sum_k e^{z_k(x)/T}
```

This is the **log-sum-exp** of the logits (scaled by $`T`$). For $`T=1`$: $`s_{energy}(x) = \log \sum_k e^{z_k}`$.

### 4.3 Why Energy Outperforms MSP: Detailed Analysis

**MSP:** $`s_{MSP}(x) = \max_k \hat{p}_k = \max_k \frac{e^{z_k}}{\sum_j e^{z_j}}`$

The denominator $`\sum_j e^{z_j}`$ is shared. MSP only uses the **maximum** of the logits relative to the normalisation. It discards information about the distribution of all other logits.

**Energy:** $`s_{energy}(x) = \log \sum_k e^{z_k}`$

Energy uses information from **all** logits — their magnitudes matter. If all logits are large (indicating the input strongly activates the entire feature space), energy is high even if the maximum is not particularly higher than the others.

**Concrete example:**

Two inputs with different OOD status:
```
Input A (in-distribution): z = [5.0, 1.0, 0.5, 0.8]
  MSP: softmax([5,1,0.5,0.8])_1 ≈ 0.968
  Energy: log(e^5 + e^1 + e^0.5 + e^0.8) ≈ log(148.4+2.72+1.65+2.23) ≈ log(155) ≈ 5.04

Input B (OOD, all logits activated): z = [2.5, 2.3, 2.1, 2.2]
  MSP: softmax([2.5,2.3,2.1,2.2])_1 ≈ 0.278   ← LOW (correctly flagged by MSP)
  Energy: log(e^2.5 + e^2.3 + e^2.1 + e^2.2) ≈ log(12.18+9.97+8.17+9.02) ≈ log(39.3) ≈ 3.67

Input C (OOD, single large logit): z = [8.0, 0.1, 0.2, 0.1]
  MSP: softmax([8,0.1,0.2,0.1])_1 ≈ 0.999   ← HIGH (MSP FAILS: false IN-DISTRIBUTION)
  Energy: log(e^8 + e^0.1 + e^0.2 + e^0.1) ≈ log(2981+1.1+1.2+1.1) ≈ log(2984) ≈ 8.0
```

Input C demonstrates MSP's critical failure: a large single logit (e.g., due to OOD features accidentally aligning with one weight vector) makes MSP look confident. But Energy also scores Input C as high-energy in-distribution. To address this, energy-based training explicitly shapes the energy surface.

### 4.4 Energy-Based Training: Shaping the Energy Landscape

Post-hoc energy scoring is good but not optimal. Liu et al. [2] propose training the model to assign:
- **Low energy** to in-distribution inputs
- **High energy** to out-of-distribution inputs

Using a **hinge loss** with margin parameters $`m_{in} < m_{out}`$:

```math
\mathcal{L}_{energy} = \mathbb{E}_{x_{in} \sim P_{in}}\left[\max(0, E(x_{in}) - m_{in})^2\right] + \mathbb{E}_{x_{out} \sim P_{out}}\left[\max(0, m_{out} - E(x_{out}))^2\right]
```

Total loss: $`\mathcal{L} = \mathcal{L}_{CE} + \lambda \mathcal{L}_{energy}`$

**Effect:** The model learns to produce tightly clustered, low-energy representations for ID inputs (low log-sum-exp → tight logit distribution with one clear winner) and dispersed, high-energy representations for OOD inputs.

**Results [2]:**
- Baseline (MSP) FPR95: 51.5%
- Energy score (post-hoc): 33.5% (18% absolute reduction)
- Energy score (with training): **~10%** (over 40% absolute reduction)

**Critical trade-off:** Energy training requires access to OOD data during training — which may not be available in clinical mental health settings.

```python
def energy_score(logits: torch.Tensor, temperature: float = 1.0) -> torch.Tensor:
    """
    Energy-based OOD score.
    logits: (batch, C) unnormalised class logits
    returns: (batch,) energy score; higher = more in-distribution
    """
    return temperature * torch.logsumexp(logits / temperature, dim=1)

def energy_loss(logits_in: torch.Tensor, logits_out: torch.Tensor, 
                m_in: float = -25.0, m_out: float = -7.0) -> torch.Tensor:
    """Energy-based training loss."""
    E_in = -energy_score(logits_in)   # negate: lower energy for in-distribution
    E_out = -energy_score(logits_out)
    
    loss_in = torch.clamp(E_in - m_in, min=0).pow(2).mean()
    loss_out = torch.clamp(m_out - E_out, min=0).pow(2).mean()
    return loss_in + loss_out
```

## 5. Mahalanobis Distance: Feature-Space Detection

### 5.1 Motivation: Beyond the Output Layer

MSP and energy scores use only the **final layer logits**. The penultimate representation $`h(x)`$ contains richer geometric information about where the input lies in the learned feature space. Lee et al. [4] proposed exploiting this geometry.

### 5.2 Class-Conditional Gaussian Fitting

After training, compute the class-conditional empirical statistics from training features:

**Class means:**
```math
\hat{\mu}_c = \frac{1}{|D_c|} \sum_{x \in D_c} h(x), \quad c = 1, \ldots, C
```

**Tied covariance (pooled):**
```math
\hat{\Sigma} = \frac{1}{N} \sum_{c=1}^C \sum_{x \in D_c} (h(x) - \hat{\mu}_c)(h(x) - \hat{\mu}_c)^\top, \quad \hat{\Sigma} \in \mathbb{R}^{d \times d}
```

This fits $`C`$ Gaussians in the $`d`$-dimensional feature space with a shared covariance structure — the **linear discriminant analysis (LDA)** assumption.

### 5.3 The Mahalanobis Score

For a test input $`x^*`$, compute the maximum Mahalanobis confidence score across all classes:

```math
M(x^*) = \max_{c \in \{1,\ldots,C\}} \; \left[-(h(x^*) - \hat{\mu}_c)^\top \hat{\Sigma}^{-1} (h(x^*) - \hat{\mu}_c)\right]
```

The negative squared Mahalanobis distance to the nearest class centroid. High $`M(x^*)`$ = close to a class centroid in Mahalanobis metric = likely in-distribution.

**Mahalanobis distance vs. Euclidean distance:**
The covariance $`\hat{\Sigma}`$ accounts for the shape of the feature distribution. Features with high variance (spread-out in training) contribute less to the distance; features with low variance (tightly clustered in training) contribute more. This is crucial — BERT's 768-dimensional representation has complex anisotropic structure, and Euclidean distance would overweight high-variance dimensions.

### 5.4 Input Preprocessing (Combined with ODIN)

Lee et al. [4] also apply a similar input perturbation:

```math
\tilde{x} = x + \varepsilon \cdot \text{sign}(\nabla_x M(x))
```

This moves $`x`$ toward the nearest class centroid in feature space, amplifying the difference between ID and OOD inputs.

### 5.5 Multi-Layer Feature Aggregation

A key improvement: instead of using only the penultimate layer, compute Mahalanobis scores at **multiple layers** and take a weighted combination:

```math
M_{total}(x^*) = \sum_l \alpha_l \cdot M_l(x^*)
```

where $`M_l`$ is the Mahalanobis score at layer $`l`$ and $`\alpha_l`$ are weights learned by logistic regression on a small validation set.

**For BERT (12 layers):** Earlier layers capture syntactic features, later layers semantic features. A text that is syntactically in-distribution but semantically OOD (e.g., correct grammar but clinical vocabulary) will show high distance at later layers but low distance at earlier layers. Multi-layer aggregation captures both signals.

### 5.6 Practical Limitations

**Covariance inversion:** $`\hat{\Sigma}^{-1}`$ requires inverting a $`768 \times 768`$ matrix. This is $`O(d^3)`$ — feasible for $`d=768`$ but must be done offline. Requires storing $`\hat{\Sigma}^{-1}`$ (768×768 float32 = 2.36MB).

**Assumption violation:** The class-conditional Gaussian assumption is almost certainly false for BERT representations. However, LDA is known to be robust to this assumption in practice when sample sizes are large.

**Spurious correlations in fine-tuned models:** After fine-tuning on a small mental health dataset, the feature distribution may be poorly estimated from the limited training data. The class centroids may not accurately reflect the true in-distribution geometry.

## 6. ReAct and ASH: Activation-Based Detectors

### 6.1 ReAct (Rectified Activations)

Sun et al. (2021) proposed **ReAct**: truncate the penultimate layer activations at a threshold before computing logits:

```math
h_{react}(x) = \min(h(x), c)
```

where $`c`$ is a threshold (typically chosen as the 90th percentile of activation values on the training set). OOD inputs tend to have activation patterns with higher magnitude than in-distribution inputs — truncating suppresses the OOD signal in the activations.

**Why this works:** Pre-trained models (especially BERT) develop activation patterns that are well-bounded for in-distribution inputs. OOD inputs can cause activations to fire in unexpected magnitudes — ReAct clips these, making OOD inputs look more like "don't know" rather than confidently wrong.

### 6.2 ASH (Activation Shaping)

**ASH** (activation shaping) is a variant that goes further: instead of truncating, it sets some activations to zero and normalises the rest:

```python
def ash_s(h: torch.Tensor, percentile: float = 65) -> torch.Tensor:
    """Activation Shaping (simplified)."""
    threshold = torch.quantile(h.abs(), percentile / 100.0)
    h_out = h.clone()
    h_out[h.abs() < threshold] = 0    # zero out small activations
    return h_out
```

## 7. Semantic Rarity in NLP: A Token-Level Analysis

### 7.1 From Global OOD to Token-Level Rarity

Standard OOD detection treats the **entire input** as either in- or out-of-distribution. For NLP, a more granular view is needed: individual tokens, phrases, or semantic concepts within an otherwise in-distribution text may be rare or unseen.

**The key distinction:** A post like *"I've been feeling really anhedonic lately, my SSRI isn't helping"* is not globally OOD — it's a mental health post on a mental health platform. But the tokens `"anhedonic"` and `"SSRI"` are semantically rare, appearing infrequently in MentalBERT's training data. Their representations are less reliable, and predictions involving them should carry more uncertainty.

### 7.2 Operationalising Semantic Rarity at the Token Level

**Token Frequency Score:**

For each token $`t`$ in vocabulary $`\mathcal{V}`$, let $`\text{freq}(t)`$ be its frequency in the model's pre-training corpus. The **token rarity** score of an input sequence $`x = (t_1, \ldots, t_n)`$:

```math
\text{rarity}_{token}(x) = \frac{1}{n} \sum_{i=1}^n \log\left(\frac{1}{\text{freq}(t_i) + 1}\right) = \frac{1}{n} \sum_{i=1}^n \text{IDF}(t_i)
```

This is the **average IDF** (inverse document frequency) of input tokens — a standard measure of token rarity.

**For subword tokenisation (BERT/MentalBERT WordPiece):**
Continuation tokens (prefixed with `##`) are inherently more frequent than words — the token `"##ing"` appears in virtually every document. The rarity score should be computed over **word-level** reconstructions, not subword tokens.

```python
def compute_token_rarity(
    input_ids: list[int],
    token_freq: dict[int, float],   # token_id → frequency in pre-training corpus
    tokenizer,
    alpha: float = 1e-3
) -> float:
    """
    Compute average IDF of word-level tokens.
    Continuation tokens (##-prefixed) are merged with their preceding token.
    """
    tokens = tokenizer.convert_ids_to_tokens(input_ids)
    
    word_rarities = []
    current_word_freq = None
    
    for token, tok_id in zip(tokens, input_ids):
        if token in ['[CLS]', '[SEP]', '[PAD]']:
            continue
        if token.startswith('##'):
            # Continuation: merge into current word (use minimum frequency)
            current_word_freq = min(current_word_freq, token_freq.get(tok_id, alpha))
        else:
            if current_word_freq is not None:
                word_rarities.append(-np.log(current_word_freq + alpha))
            current_word_freq = token_freq.get(tok_id, alpha)
    
    if current_word_freq is not None:
        word_rarities.append(-np.log(current_word_freq + alpha))
    
    return np.mean(word_rarities) if word_rarities else 0.0
```

### 7.3 Contextual Rarity: Embedding-Space Distance

Beyond individual token rarity, the **contextual representation** of a full input may be rare — the specific combination of tokens may not appear together in training, even if individual tokens are common.

**Approach: Nearest-Neighbour Distance in Embedding Space**

After extracting `[CLS]` embeddings $`h(x)`$ from the trained BERT model for all training examples, compute the distance from a new input to its $`k`$-nearest neighbours in the training set:

```math
d_{kNN}(x^*) = \frac{1}{k} \sum_{i=1}^k \|h(x^*) - h(x_{(i)})\|_2
```

where $`x_{(1)}, \ldots, x_{(k)}`$ are the $`k`$ nearest training examples in embedding space.

Sun et al. (2022) showed that the **negative** $`k`$-NN distance is a strong OOD detector, outperforming energy and Mahalanobis distance on text OOD benchmarks.

**Efficiency:** Exact $`k`$-NN in $`\mathbb{R}^{768}`$ is $`O(N \cdot d)`$ per query (linear scan). For large training sets ($`N > 10^5`$), use approximate nearest-neighbour indices (FAISS, Annoy) for sub-linear search.

```python
import faiss
import numpy as np

def build_knn_index(train_embeddings: np.ndarray) -> faiss.Index:
    """Build FAISS flat L2 index for nearest-neighbour search."""
    d = train_embeddings.shape[1]  # 768
    index = faiss.IndexFlatL2(d)
    index.add(train_embeddings.astype(np.float32))
    return index

def knn_ood_score(
    query_embedding: np.ndarray,
    index: faiss.Index,
    k: int = 5
) -> float:
    """Lower score = more likely OOD."""
    D, _ = index.search(query_embedding[np.newaxis].astype(np.float32), k)
    return -np.mean(D)  # negative average distance; higher = more ID
```

### 7.4 Semantic Rarity Taxonomy for Mental Health NLP

**Level 1: Lexical Rarity** — individual tokens that are rare in the training corpus

Examples:
- `"anhedonia"` (clinical term, rare in general-domain corpora)
- `"SI"` (abbreviation for suicidal ideation — common in clinical notes but rare elsewhere)
- `"dysphoric"` (clinical adjective, rarely self-applied)

Detection: IDF score against training corpus vocabulary frequencies.

**Level 2: Conceptual Rarity** — combinations of tokens that are rare even if individual tokens are common

Examples:
- `"feeling numb" AND "sleeping too much" AND "not caring"` — the co-occurrence of multiple depression markers in a single post
- `"voices telling me" AND "real" AND "scared"` — psychosis-adjacent language

Detection: N-gram frequency analysis, topic model perplexity.

**Level 3: Pragmatic Rarity** — same tokens, different pragmatic function

Examples:
- `"I want to die"` — literal (crisis) vs. colloquial ("this meeting is killing me")
- `"end it all"` — suicidal ideation vs. completing a project
- `"pills"` — medication vs. recreational use

Detection: Requires discourse context modelling, which is an open research problem. Current NLP models frequently fail here.

## 8. Textual OOD Detection: NLP-Specific Considerations

### 8.1 The Discrete Input Problem

Unlike images (continuous pixel values), text is **discrete**. The input perturbation methods (ODIN, Mahalanobis with perturbation) that work well for images require gradient computation with respect to the input — which is a discrete object.

**Solutions for text:**
1. **Operate in embedding space:** Perturb the **word/token embeddings** (continuous), not the discrete tokens. The gradient with respect to the input embedding matrix is well-defined.
2. **Use representation-level detectors:** Mahalanobis distance on BERT's `[CLS]` embedding, k-NN distance — these don't require input perturbation.
3. **Energy score:** Works directly on logits, no input perturbation needed.

For NLP, **energy score and k-NN distance** are the most practically applicable methods.

### 8.2 The Tokenisation OOD Connection

A critical and often overlooked interaction: tokenisation affects the representation of rare words. When MentalBERT encounters `"anhedonia"`, it tokenises it as:

```
"anhedonia" → ["an", "##hed", "##on", "##ia"]   (4 subword tokens)
```

Each subword is common in the training corpus, so they have well-trained embeddings. But the **composition** of `["an", "##hed", "##on", "##ia"]` into a meaningful clinical representation was only learned from the relatively rare occurrences of `"anhedonia"` in the pre-training corpus.

**The fragmentation-rarity relationship:**
High tokenisation fragmentation ($`F(x)`$ — the mean number of subword tokens per word) is a proxy for semantic rarity. Words that fragment heavily were either:
1. Absent from pre-training (true OOV → definitely semantically rare)
2. Rare in pre-training (fragmented into common subwords → moderate semantic rarity)
3. Common but morphologically complex (e.g., compound words in German) → false positive

For mental health NLP with English text, case 2 dominates: high fragmentation strongly predicts semantic rarity.

### 8.3 Benchmark Datasets for NLP OOD

| In-Distribution | OOD Dataset | Task | Notes |
| :--- | :--- | :--- | :--- |
| 20 Newsgroups (4 classes) | Other 16 classes | Text classification | Standard benchmark [1] |
| SST-2 (sentiment) | WMT16-EN (news text) | Binary sentiment | Domain shift |
| IMDb | SNLI, SST-2 | Sentiment classification | Format shift |
| MentalHealth Reddit | Wikipedia, News articles | Crisis classification | Semantic shift |
| Reddit depression posts | Medical research abstracts | Depression detection | Register shift |

**The mental health OOD challenge:** Unlike standard NLP OOD benchmarks where ID and OOD are clearly different (e.g., sentiment vs. news), mental health OOD often involves **near-domain shifts** — medical abstracts vs. Reddit posts about the same topic. This makes it a much harder OOD problem.

## 9. OOD Detection Evaluation: Metrics and Protocols

### 9.1 The Binary Classification Framing

OOD detection is a binary classification problem: ID inputs are the positive class, OOD inputs are negative. Standard binary classification metrics apply:

**AUROC (Area Under ROC Curve):**
```math
\text{AUROC} = P(s(x_{in}) > s(x_{out}))
```

The probability that a randomly drawn ID input receives a higher OOD score than a randomly drawn OOD input. Independent of threshold choice.

**FPR95 (False Positive Rate at TPR=95%):**
Choose threshold $`\delta`$ such that $`P(s(x_{in}) \geq \delta) = 0.95`$ (95% of ID inputs are correctly classified). Measure $`P(s(x_{out}) \geq \delta)`$ — the fraction of OOD inputs that are incorrectly accepted.

**AUPR-In (Area Under Precision-Recall curve, ID as positive):**
Useful when the ratio of ID to OOD inputs is very imbalanced (as in clinical settings where the vast majority of inputs are in-distribution).

## 10. Wild vs. Curated OOD: The Open-World Problem

### 10.1 Wild OOD

In deployment, the model may encounter **completely unexpected** inputs — languages it wasn't trained on, intentionally adversarial posts, content from entirely different domains (e.g., financial scams posted to mental health forums). This is "wild OOD."

Standard OOD benchmarks use curated OOD datasets that were constructed with knowledge of the ID task. Wild OOD is harder — no benchmark can capture all possible unexpected inputs.

### 10.2 Detecting Wild OOD

Two complementary approaches:

**Semantic-level:** Use embedding distance (k-NN or Mahalanobis) to detect inputs far from any training class. Works for any content.

**Syntactic/lexical level:** Use language identification, character-level n-gram models, or perplexity under a language model. An English-trained model should flag French inputs via language ID before the classifier ever sees them.

Combining both levels yields a layered OOD signal — from surface-level features (language ID, fragmentation, lexical rarity) to semantic-level signals (embedding distance).

## 11. Relevance to Reliability Estimation

### 11.1 The Philosophy of Soft OOD

Standard OOD detection makes a binary decision: accept or reject. A more nuanced approach to reliability estimation uses OOD signals to make a **soft** decision: modulating the model's confidence or triggering human review based on the continuous degree of distributional shift.

This is clinically more appropriate than binary accept/reject:
- A post with unusual vocabulary (high rarity) might be slightly hedged.
- A post in a clinical register (high fragmentation + high rarity) might be significantly hedged.
- A post that's clearly in-domain (common vocabulary, low fragmentation) receives no adjustment.

### 11.2 The Information Hierarchy of OOD Signals

The OOD signals form a hierarchy of granularity:

```
Granularity Level    Signal                         Signal Strength
─────────────────────────────────────────────────────────────────
Token level       ←  Tokenisation fragmentation F(x)  [high]
                  ←  IDF-based lexical rarity          [high]
                  
Representation    ←  k-NN distance                     [highest]
level             ←  Mahalanobis distance               [high]
                  
Output level      ←  Energy score E(x)                 [medium]
                  ←  MSP 1 - max p̂                     [low]
```

Higher-granularity signals (token-level) are cheaper to compute and directly connected to linguistic properties. Representation-level signals are more expensive but theoretically stronger. Advanced reliability estimators combine these based on computational budget.

### 11.3 Semantic Rarity as the Bridge

The concept of **semantic rarity** bridges OOD detection and reliability estimation. It reframes the OOD question from "is this input from a different domain?" to "are there specific linguistic elements in this input that the model cannot reliably process?" 

This is a more fine-grained and clinically actionable question, moving beyond simple global uncertainty metrics or binary OOD rejection.
