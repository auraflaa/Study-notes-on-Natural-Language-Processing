# Reliability Evaluation Metrics

These are comprehensive study notes. Every factual claim is cited. References focus on the standard metrics used to evaluate predictive uncertainty, calibration, and selective prediction.

To prove that a reliability estimator is superior to raw Softmax $p_{max}$, we must evaluate it rigorously. The evaluation of reliability estimators generally falls into three distinct mathematical categories: **Calibration Metrics**, **Proper Scoring Rules**, and **Ranking/Separation Metrics**.

### Conceptual Hierarchy

```text
Evaluating Reliability
          ↓
  1. Calibration (ECE, MCE, AdaECE)
          ↓
  2. Scoring Rules (NLL, Brier Score)
          ↓
  3. Error Detection (AUROC, AUPRC)
          ↓
  4. Abstention Quality (AURC, FPR95)
```

## 1. Calibration Metrics

Calibration measures how well a model's predicted confidence matches its true empirical accuracy. If a model predicts an event will happen with $80\%$ confidence, it should be correct exactly $80\%$ of the time.

### 1.1 Expected Calibration Error (ECE)
ECE is the most widely used calibration metric [1]. It partitions all predictions into $M$ equally spaced confidence bins (e.g., $0.0-0.1$, $0.1-0.2$).
For each bin $B_m$, it computes the difference between the average accuracy and the average confidence:
$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{n} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
- **Flaw:** ECE is highly sensitive to the number of bins $M$. Furthermore, for highly accurate models, most predictions fall into the highest bin (e.g., $0.9-1.0$), making the metric heavily biased and mathematically unstable.

### 1.2 Maximum Calibration Error (MCE)
Instead of averaging the error across all bins, MCE simply takes the worst-case bin:
$$\text{MCE} = \max_m \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
- **Use Case:** Critical in high-stakes domains like medicine, where we cannot tolerate *any* specific confidence range being dangerously overconfident.

### 1.3 Adaptive ECE (AdaECE)
To fix ECE's problem of uneven bin populations, AdaECE spaces the bins such that every bin contains exactly the same *number of samples* rather than covering the same *confidence width* [2].

### 1.4 Comparison: Calibration Metrics

| Metric | Mathematical Focus | Primary Flaw | Relevance to Reliability Estimation |
| --- | --- | --- | --- |
| **ECE** | Average absolute error across equal-width bins. | Highly sensitive to bin size; over-weights the densest bin. | Baseline comparison. If a geometric score ($JSD$) is Platt-scaled, it should yield lower ECE than Softmax. |
| **MCE** | Maximum absolute error in any bin. | Highly sensitive to outliers in sparsely populated bins. | Measures the worst-case clinical risk of the estimator. |
| **AdaECE** | Average absolute error across equal-mass bins. | Can obscure regions of the confidence space with low density. | The most rigorous way to evaluate scaled probabilities. |

## 2. Proper Scoring Rules

A scoring rule is "strictly proper" if it is uniquely minimized when the predicted probabilities exactly match the true data distribution [3]. 

### 2.1 Negative Log-Likelihood (NLL)
Also known as Cross-Entropy Loss, NLL evaluates the probability assigned specifically to the true label $y_i$:
$$\text{NLL} = -\frac{1}{n} \sum_{i=1}^n \log(\hat{p}_{y_i}(x_i))$$
- **Why it matters:** NLL heavily penalizes overconfident errors. If the model is $99\%$ confident in the wrong class, the NLL penalty approaches infinity.

### 2.2 Brier Score
The Brier Score measures the mean squared difference between the predicted probability distribution and the one-hot encoded true label:
$$\text{Brier} = \frac{1}{n} \sum_{i=1}^n \sum_{c=1}^K (\hat{p}_c(x_i) - y_{i,c})^2$$

**The Algebraic Decomposition of the Brier Score:**
Brier Score is bounded between 0 and 2. It is particularly powerful because it can be mathematically decomposed into three distinct components [4]:
$$\text{Brier} = \text{Reliability} - \text{Resolution} + \text{Uncertainty}$$

1. **Reliability:** How close the forecasted probabilities are to the true frequencies (equivalent to Mean Squared Calibration Error).
2. **Resolution:** How well the predictions separate the different classes (higher is better, hence the subtraction).
3. **Uncertainty:** The irreducible variance (entropy) of the dataset itself, independent of the model.

**Relevance to reliability estimation:** By evaluating the Brier Score of a reliability estimator's estimated probabilities vs. the Softmax probabilities, we can isolate exactly *why* it is better. A well-designed estimator should mathematically decrease the "Reliability" penalty without hurting "Resolution".

## 3. Error Detection (Ranking Metrics)

Used as an error detector, a geometric reliability score acts as a binary classifier: it must distinguish between *Accurate Predictions* and *Errors* based on $JSD$. 

### 3.1 AUROC for Error Detection
The Area Under the Receiver Operating Characteristic Curve plots the True Positive Rate (TPR) against the False Positive Rate (FPR) across all possible thresholds.
- **Mathematical Interpretation:** If we pick a random Accurate Prediction and a random Error, the AUROC is exactly the probability that the reliability estimator (e.g., $JSD$) assigns a higher uncertainty score to the Error. 
- $\text{AUROC} = 0.5$ is random guessing; $\text{AUROC} = 1.0$ is perfect separation.

### 3.2 Area Under the Precision-Recall Curve (AUPRC)
AUROC can be highly misleading if the dataset is imbalanced. For example, if a model is $95\%$ accurate, there are very few errors. A model could simply predict "Accurate" for everything and achieve a deceptively high AUROC due to the massive number of True Negatives dragging down the FPR. AUPRC removes True Negatives from the equation entirely by evaluating Precision vs. Recall.
- **AUPRC-Error:** Treating "Errors" as the positive class. This evaluates how well the reliability score identifies the rare mistakes. Highly sensitive to false alarms.
- **AUPRC-Success:** Treating "Accurate Predictions" as the positive class.

### 3.3 Comparison: Error Detection Metrics

| Metric | Invariant to Class Imbalance? | Best Used When... |
| --- | --- | --- |
| **AUROC** | Yes. | You need a general summary of separation quality across all thresholds. |
| **AUPRC-Error** | No. | The model is highly accurate, and you care deeply about finding the rare but catastrophic errors without causing fatigue. |
| **AUPRC-Success** | No. | You are prioritizing the automation of safe cases rather than the flagging of dangerous ones. |

## 4. Abstention Quality Metrics

When a reliability score is moved into Selective Prediction (Note 15), we evaluate the efficiency of the threshold.

### 4.1 Area Under the Risk-Coverage Curve (AURC)
As discussed in Note 15, the Risk-Coverage curve plots the error rate (Selective Risk) against the fraction of data the model is allowed to predict on (Coverage). 
- **AURC:** The integral of this curve [5]. A lower AURC means the model successfully filters out errors while maintaining high coverage. 
- **E-AURC (Expected AURC):** Baseline accuracy heavily dictates AURC (a $99\%$ accurate model will always have a lower AURC than an $80\%$ accurate model, regardless of abstention quality). E-AURC subtracts the theoretically optimal AURC for that specific model, creating a purely baseline-independent metric for comparing reliability estimators.

### 4.2 FPR95 (False Positive Rate at 95% TPR)
Originating from the Out-of-Distribution (OOD) detection literature [6], FPR95 asks: *"If we set a threshold $\theta$ such that we successfully catch 95% of all errors (True Positive Rate = 0.95), what percentage of correct predictions are accidentally rejected (False Positive Rate)?"*

### 4.3 Comparison: Abstention Metrics

| Metric | What it measures | Clinical Translation |
| --- | --- | --- |
| **AURC** | The raw area under the risk-coverage curve. | "Overall, how safe is the system as we automate more data?" |
| **E-AURC** | AURC minus the optimal possible AURC. | "How close is our $JSD$-based score to a perfect oracle that knows exactly which predictions are wrong?" |
| **FPR95** | False alarms when strict safety is enforced. | "If the hospital demands we catch 95% of AI errors, how many extra human hours will we waste reviewing false alarms?" |

## 5. Feature Attribution and Ablation Science

To prove that a complex reliability score is strictly necessary, we must isolate its components to mathematically defend the usage of JS Divergence over simpler geometric features.

### 5.1 The Mathematical Feature Set
Let $P_{model}$ be the Softmax prediction, and $Q_{kNN}$ be the neighborhood empirical distribution.
1. **$JSD$:** $H\left(\frac{P_{model}+Q_{kNN}}{2}\right) - \frac{1}{2}\left(H(P_{model}) + H(Q_{kNN})\right)$
2. **Parametric Entropy:** $H(P_{model}) = -\sum p_c \log p_c$
3. **Neighborhood Entropy:** $H(Q_{kNN}) = -\sum q_c \log q_c$
4. **Density ($\bar{D}$):** Average distance $\frac{1}{k} \sum d(x, x_i)$

### 5.2 The Critical Ablation: JSD vs Neighborhood Entropy
A reviewer might ask: *"If the neighborhood is highly mixed ($H(Q_{kNN})$ is high), the model is likely to fail. Why do you need JSD?"*

**The Mathematical Defense:**
Consider two neighborhoods for a model that predicts Class A with $P_{model} = [1.0, 0.0]$.
1. **Neighborhood 1 (Pure Class A):** $Q_{kNN} = [1.0, 0.0]$. $H(Q) = 0$. $JSD = 0$.
2. **Neighborhood 2 (Pure Class B):** $Q_{kNN} = [0.0, 1.0]$. $H(Q) = 0$. $JSD \approx 0.693$.

In both cases, non-parametric entropy $H(Q_{kNN})$ is identically zero. Relying solely on the neighborhood entropy would fail to distinguish between total agreement and catastrophic disagreement. $JSD$ computes the relational conflict. 

### 5.3 Likelihood Ratio Evaluation
We evaluate the unique contribution of $JSD$ by fitting nested logistic regression models predicting the Error event $E$:
- **M0 (Baseline):** $\text{logit}(P(E=1)) = \beta_0 + \beta_1 H(Q_{kNN})$
- **M1 (Proposed):** $\text{logit}(P(E=1)) = \beta_0 + \beta_1 H(Q_{kNN}) + \beta_2 JSD$

A Likelihood Ratio Test (LRT) yielding a $p$-value $< 0.05$ strictly proves that $JSD$ contributes predictive variance that is completely orthogonal to raw geometric uncertainty.
